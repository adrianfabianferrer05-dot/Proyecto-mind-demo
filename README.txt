BAR CINCA - DEMO SIMPLE PARA VERCEL

Esta versión está hecha a propósito en un único archivo index.html.
No necesita npm, React, Vite ni compilación.

Para subirla desde iPhone:
1. Sube index.html a la raíz del repositorio.
2. En Vercel, importa el repositorio.
3. Framework preset: Other.
4. Build Command: vacío / none.
5. Output Directory: vacío.
6. Deploy.

Si ya tienes archivos de un proyecto Vite fallido en el repositorio,
lo más limpio es crear un repositorio nuevo para esta demo simple.
